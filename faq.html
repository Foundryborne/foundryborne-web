What is Foundryborne?

Foundryborne is an open-source community initiative that develops the official implementation of Darrington Press's Daggerheart tabletop roleplaying game system for Foundry Virtual Tabletop (Foundry VTT). It provides automated duality dice rolls, custom actor sheets, SRD compendiums, and many advanced features. It started out as an inofficial System, but has been adopted by Darrington Press as the official implementation since GenCon 2026.

Why is it called Foundryborne?

Communities in Daggerheart are all named -borne (Wildborne, Seaborne, Loreborne... etc.). Since this is a Community Project for Foundry VTT, we decided to name it Foundryborne.

How do I install the Daggerheart system on Foundry VTT?

Installing is fast and straightforward:

  1. Launch your Foundry VTT application.
  2. Go to the Game Systems tab and click Install System.
  3. Search for Daggerheart in the search bar.
  4. Click Install and create your Daggerheart world!
How do I purchase and activate Premium Modules?

Premium modules can be acquired through our Premium Content Marketplace. Please note that currently the modules are only available for preorder.

Where can I report bugs or request new features?

We welcome contributions and bug reports! You can submit issues directly on our GitHub Issues tracker or join our active community on Discord to discuss ideas with the dev team.

Do you have an AI Policy?

The Foundryborne Daggerheart system does not make use of AI (generative or otherwise) for any area of its implementation. We expect all contributors to follow this same policy when contributing with a pull request; contributions made using AI will be rejected outright.

Is this system officially affiliated with Darrington Press?

Foundryborne remains an independent community development team. Daggerheart and related trademarks are owned by Darrington Press LLC. Official Premium Content Modules are available for the system, but not required to use the system.
