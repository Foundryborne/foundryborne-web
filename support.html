Daggerheart System Issues

Support for the core Daggerheart Game System for Foundry VTT is actively provided by the Foundryborne developer team and our community maintainers.

What we support:

  • System installation, updates, and software compatibility
  • Duality dice roll automation and actor/item sheet functionality
  • SRD compendium items, classes, ancestries, and domain cards
  • System bug reports, feature requests, and community contributions

Module Content Issues

Support for module content inside paid modules (such as Core Rulebook journal entries, artwork, and adventure packs) is provided by the publisher of the content module.

Module Publisher Responsibility:

  • Official module artwork, map scenes, and campaign journals
  • Module-specific compendium content and text errata
  • Inquiries regarding published module contents or upcoming packs

* Note: Module publishers are responsible only for module content. Payment, billing, and key redemption are handled by the store platform (e.g., Foundry VTT Store).

Before Reporting a System Bug

Please disable all third-party modules (or test in a clean world with only the Daggerheart system active) to confirm that the issue is not caused by a module conflict. Many common issues stem from outdated or incompatible third-party modules!
